# pokemon-debug

Scripts to compile, decompile and modify the scripts of popular Pokemon fan games made with MKXP/Pokemon Essentials, and git patches to enable debug mode on them. Currently supports [Pokemon Desolation](desolation), [Pokemon Flux](flux), [Pokemon Rejuvenation](rejuvenation), [Pokemon Uranium](uranium), and [Pokemon Xenoverse](xenoverse).

For Pokemon Reborn, just use the password "debug".
