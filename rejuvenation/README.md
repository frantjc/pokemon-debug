# Pokemon Rejvenation

Pokemon Rejvenation puts its Ruby scripts directly in the `Scripts` directory of the game's installation folder.

Contains patches for enabling custom crests for Archeops and Accelgor as well as enabling mini debug. To use them, install [`git`](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) to apply a patch.

```sh
make crests mini-debug POKEMON_REJUVENATION=path/to/pokemon/rejuvenation
```
